#### 🛠️ Cập nhật Sản phẩm & Công cụ

* **Claude Code 2.1.224 — nhắn tin giữa các phiên độc lập:** Anthropic bổ sung `ListAgents` và `SendMessage`, cho phép một phiên Claude Code tìm rồi gửi nội dung văn bản cho phiên khác; phiên đang chạy nhận tin giữa hai tool call, còn phiên rảnh sẽ bắt đầu một lượt mới. Trên cùng máy, tin nhắn đi qua socket riêng của từng phiên và không qua máy chủ Anthropic; với phiên trên máy khác hoặc Claude Code web, phiên nhận có thể trả lời qua Remote Control. Tính năng yêu cầu Claude Code `2.1.224+`, hiện chỉ hỗ trợ macOS và Linux (bao gồm WSL 2), không chuyển lịch sử hội thoại hay tệp, đồng thời vẫn giữ ranh giới quyền theo từng phiên. Với workflow lập trình song song, đây là cơ chế bàn giao quyết định, cảnh báo thay đổi phá vỡ tương thích và báo trạng thái mà không phải sao chép ngữ cảnh thủ công; tuy nhiên nhóm cần cấu hình `crossSessionInbound`, giới hạn peer ngoài máy và quyền `SendMessage`/`ListAgents` phù hợp với mức tin cậy. Nguồn: [Claude Code Docs — Cross-session messaging](https://code.claude.com/docs/en/cross-session-messaging), [Claude Code — changelog 2.1.224](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md#21224).
