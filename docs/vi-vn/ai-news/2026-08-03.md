### 📰 ĐIỂM TIN AI NÓNG - 03/08/2026

#### 🚀 Model Releases & Đột phá Công nghệ
* **Anthropic — Claude Opus 5 cho game 3D sinh từ một prompt:** Các thử nghiệm cộng đồng được công bố ngày 02/08 cho thấy Opus 5 có thể tạo game bắn súng, đua xe, trượt tuyết và mô phỏng Minecraft chạy trong trình duyệt từ một prompt, với hình học, texture, vật lý và đôi khi cả nhạc đều được sinh thành mã thay vì dùng asset ngoài. Đây chưa phải benchmark chuẩn hóa: các so sánh với GPT-5.6 Sol, Kimi K3 hoặc Claude 4 Opus chủ yếu là demo do người dùng tự chọn, vì vậy chỉ nên xem là tín hiệu về chất lượng artifact và khả năng lặp lại, không phải bảng xếp hạng tổng quát. Công bố gốc của Anthropic cho biết Opus 5 đạt điểm ARC-AGI 3 gấp ba mô hình đứng sau, pass rate trên Zapier AutomationBench khoảng 1,5 lần mô hình kế tiếp ở cùng chi phí, và có giá 5 USD/triệu input token cùng 25 USD/triệu output token; các số liệu này do hãng báo cáo. Với lập trình viên, bước tiến thực dụng nằm ở việc mô hình có thể tự tạo, chạy và chỉnh một artifact tương tác hoàn chỉnh trong một file HTML, nhưng vẫn cần test nhiều prompt và kiểm tra mã trước khi đưa vào production. Nguồn: [The Decoder — thử nghiệm prompt-to-game ngày 02/08](https://the-decoder.com/claude-opus-5-pushes-prompt-to-game-ai-from-rough-color-blocks-to-full-3d-prototypes-with-physics-and-music/), [Anthropic — Introducing Claude Opus 5](https://www.anthropic.com/news/claude-opus-5).

#### 🛠️ Cập nhật Sản phẩm & Công cụ
* **Mu — 67 công cụ cho agent qua một MCP endpoint:** Dự án mã nguồn mở `micro/mu` được đưa lên Hacker News ngày 02/08 và gom web search, RSS, email, thị trường, thời tiết, file, lịch, danh bạ, ứng dụng cùng nhiều dịch vụ khác vào một MCP endpoint. Thay vì chỉ bọc API bên thứ ba, Mu tự vận hành một số hạ tầng như SMTP có DKIM, feed aggregator, search index, app sandbox và storage; cùng một Go binary có thể chạy server, web app hoặc CLI, còn đăng nhập MCP dùng luồng authorization tiêu chuẩn. Cách đóng gói này giảm công sức nối nhiều MCP server riêng lẻ cho Claude Desktop, Cursor hoặc agent tự xây, nhưng giấy phép AGPL-3.0 buộc đội triển khai dịch vụ từ bản sửa đổi phải chia sẻ mã nguồn tương ứng. Dự án mới có quy mô cộng đồng nhỏ, nên nên thử trong môi trường tách biệt và rà soát kỹ quyền mail, file, lịch cùng chi phí tool call trước khi giao dữ liệu thật. Nguồn: [GitHub — micro/mu](https://github.com/micro/mu), [Hacker News — Show HN: Mu, Tools for Agents](https://news.ycombinator.com/item?id=49148899).

#### 🔬 Nghiên cứu & Học thuật (Báo cáo nổi bật)
* **Proactive Memory Agent — nhắc agent đúng lúc thay vì luôn nhồi lịch sử:** Nhóm Meta AI mô tả hiện tượng `behavioral state decay`, khi yêu cầu, lỗi đã chẩn đoán hoặc bước thử thất bại vẫn còn trong trajectory nhưng không còn chi phối quyết định của agent ở tác vụ dài. Hệ thống ghép một memory agent với action agent không sửa đổi: memory agent cập nhật kho trạng thái có cấu trúc từ cửa sổ bước gần nhất, rồi chủ động quyết định chèn lời nhắc ngắn hoặc giữ im lặng. Trên Terminal-Bench 2.0, cách này tăng pass@1 tối đa 8,3 điểm phần trăm; trên τ²-Bench tăng tối đa 6,8 điểm, và ablation cho thấy can thiệp chọn lọc tốt hơn luôn hiển thị memory bank, luôn chèn nhắc, retrieval chung hoặc chỉ dùng advisor. Công trình mới ở bản arXiv v1 và chưa qua peer review, nhưng code đã được công khai; với agent production, kết quả gợi ý nên đo riêng độ đúng của chính sách “khi nào nhắc” thay vì chỉ tăng context window. Nguồn: [arXiv — Remember When It Matters](https://arxiv.org/abs/2607.08716), [GitHub — proactive-memory-agent](https://github.com/yifannnwu/proactive-memory-agent), [The Decoder — bài phân tích ngày 02/08](https://the-decoder.com/meta-ai-uses-a-second-ai-agent-as-a-memory-coach-to-keep-long-tasks-on-track/).
