* **Cảnh báo bảo mật cho người dùng Claude Code: hơn 104.000 file `.claude/settings.local.json` nằm trên GitHub, 1.122 file chứa secret thật:** Apiiro đếm 104.185 bản sao file settings của Claude Code trong 103.617 repo public; 1.122 trong số đó chứa credential thật với khoảng 1.379 secret khác nhau — database password, API token, cloud key, SSH private key; nếu soi cả Git history và file chia sẻ khác, con số lên 2.539 credential trên gần 2.000 repo, trong đó có repo của công ty phần mềm. Nguyên nhân không phải bug mà là một thói quen dev: khi bấm "Yes, and don't ask again" cho một lệnh shell, Claude Code lưu cả lệnh vào `.claude/settings.local.json`; nếu lệnh đó mang theo password/token thì secret nằm lại trong file. File được thêm vào global gitignore nên không bị commit, nhưng cơ chế này không còn tác dụng khi clone project sang máy khác hoặc khi thư mục biến thành repo — thậm chí có trường hợp Claude Code tự commit thay đổi của file. Anthropic được cho là đã biết, Boris Cherny (head of Claude Code) nói đang cân nhắc secret scanning tích hợp sẵn và đổi cách tool xử lý command permission. Việc cần làm ngay cho repo của bạn: `git rm --cached .claude/settings.local.json`, thêm dòng đó vào `.gitignore` của project (không chỉ global), chuyển secret sang biến môi trường, và xoay vòng mọi credential từng đi qua lệnh đã approve. [Nguồn: Apiiro](https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again), [Ars Technica](https://arstechnica.com/ai/2026/11/claude-code-settings-files-expose-thousands-of-secrets-on-github/), [HN 624 điểm](https://news.ycombinator.com/item?id=50407882).

* **Meta FAIR releases e-means: thuật toán clustering trong FAISS 1.16.0 đạt loss của k-means Lloyd 25 epoch chỉ với 1,4–2,6 epoch, nhanh hơn GPU 10–45×:** Update quan trọng cho hạ tầng dữ liệu — e-means là drop-in replacement cho Lloyd's k-means, được Meta FAIR phát hành kèm FAISS 1.16.0 và công bố trên arXiv (mã 2611.09501). Con số cụ thể MarkTechPost trích từ bài báo: hội tụ tới mức loss mà Lloyd's k-means cần 25 epoch chỉ trong 1,4 đến 2,6 epoch, speedup trên GPU từ 10× tới 45×, và không cần thêm hyperparameter mới — nghĩa là pipeline vector indexing/embedding clustering chạy k-means ở quy mô lớn giảm chi phí compute gần như trực tiếp mà không phải đổi code. Câu chuyện cũng giải thích vì sao dự án e-means.github.io leo 304 điểm HN hôm qua: cộng đồng kiểm chứng chéo benchmark của một phòng lab lớn, không phải trang ẩn danh. [Nguồn: MarkTechPost](https://www.marktechpost.com/2026-11-10/meta-fair-e-means-k-means-faiss/), [arXiv:2611.09501](https://arxiv.org/abs/2611.09501), [E-means](https://e-means.github.io).
